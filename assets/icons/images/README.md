# 🚑 AI Smart Ambulance System with Sky Capsule Integration

## 📌 Project Overview
This project is a frontend prototype of an intelligent emergency transport system that combines **AI-based decision making** with an innovative **Sky Capsule transport concept** to reduce ambulance delays caused by traffic congestion.

---

## 🎯 Problem Statement
- Ambulances are often delayed due to heavy traffic
- Existing systems only suggest routes, not alternative transport
- Delay in emergency response can cost lives

---

## 💡 Proposed Solution
- AI-based smart ambulance dispatch system
- Introduces **Sky Capsule** transport running below metro flyovers
- Selects fastest mode:
  - 🚑 Ambulance (low traffic)
  - 🚡 Sky Capsule (high traffic)

---

## ⚙️ Features
- 📍 GPS-based location detection
- 🗺️ Live map using OpenStreetMap
- 🚦 Traffic-based decision system
- 🏥 Nearest hospital suggestion (demo)
- 🔄 Real-time monitoring simulation
- 📊 Simple and user-friendly UI

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Leaflet.js (for maps)
- Browser Geolocation API

---

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open `index.html` in a browser
3. Allow location access for GPS
4. Click:
   - "Use GPS"
   - "Find Best Route"
