# 🚑 AI Smart Ambulance System with Sky Capsule Integration

## 📌 Project Overview
This project presents a **smart emergency response system** that uses simple AI-based decision logic along with an innovative **Sky Capsule transport concept** to reduce ambulance delays caused by traffic congestion.

The system dynamically selects the fastest transport method:
- 🚑 Ambulance (road-based)
- 🚡 Sky Capsule (elevated, traffic-free)

---

## 🎯 Problem Statement
- Ambulances are delayed due to heavy traffic congestion
- Existing systems only provide route suggestions
- Delays in emergency response can lead to loss of lives

---

## 💡 Proposed Solution
- AI-based smart decision system
- Integration of **Sky Capsule transport** below metro flyovers
- Intelligent selection based on traffic conditions
